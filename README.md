🎮 Number Guessing Game

A beginner-friendly Python terminal game built in Termux where players try to guess a randomly generated secret number within limited attempts.

Features

- Random number generation
- Multiple attempts system
- “Too high” and “Too low” hints
- Help menu
- Exit option
- Terminal-based gameplay

Built With

- Python
- Termux
- Random module

What I Learned

This project helped me practice:

- Functions
- Loops
- Conditions
- User input handling
- Program flow control
- Randomization in Python

How to Run

python game.py
